# markdown-editor

A light weight chrome extension that lets you create, view and edit markdown files in browser. Open a markdown file or click the chrome extension icon to get started!

## Install

The extension comes with its browser bundle in `vendor/`. You can install it in Chrome directly from the extracted project folder.

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode**, click **Load unpacked**, and select this folder.
3. Open this extension's **Details** and enable **Allow access to file URLs**.
4. Drag a `.md` file into Chrome (or open its `file:///…/document.md` URL). Refresh any already-open Markdown tab.

## Features

- Automatically opens markdown viewer on markdown files
- Autosave Drafts
- View recently opened files
- Live Preview editor
- Extended markdown support
- Zoom and Font Adjustments
- Offline Support
- Tables Support
- Tab inside a table to create new table column
- Page breaks via `\newpage` or `{{< pagebreak >}}`
- Checkbox support with live updates in read mode
- Inline images via `![[image.jpg]` tag. local, relative and web urls supported.
- Print Button with PDF Support
- Save As and File Download Buttons
- Dark mode
